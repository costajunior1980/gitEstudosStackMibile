Aprendendo git e git hub com Stack Mobile

Primeiros passos no git: Considerando que o git foi instalado na máquina. Crie um pasta e coloque os arquivos que serão gerenciados pelo git; Clique no espaço vazio da pasta e procure por outras opções. Encontre a opção: open git Bash here; Será aberto um terminal. Utilize o comanto git int para criar uma pasta .git. Esta pasta será responsável pelo versionamento; use o comando git status para ver as pastas que estão sendo acompanhadas pelo git. As pastas com o nome em vermelho, não estão inseridas no versionamento do git. Adicione a pasta através do comando git add “nome da pasta”; Para adicionar todos os arquivos de uma vez: git add
